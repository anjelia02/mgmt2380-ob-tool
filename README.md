# Unspoken Expectations

A short interactive tool for making unspoken expectations visible in a working relationship. Each person rates eight everyday expectations privately, shares a code, and then reviews the gaps together.

- `index.html` redirects to the tool.
- `unspoken-expectations.html` is the tool. It runs in any modern browser and stores nothing on a server.
- `paper.md` is the accompanying paper.

Course: MGMT 2380, Organizational Behavior.
